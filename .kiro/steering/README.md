# Contexto para Kiro

Kiro carga estos documentos como contexto en cada especificación:

- [product.md](product.md): propósito, actores, capacidades y alcance.
- [tech.md](tech.md): stack, convenciones, seguridad obligatoria y estrategia de pruebas.
- [structure.md](structure.md): organización del repositorio y de los módulos.

Las decisiones aprobadas del proyecto están además en `AGENTS.md`, en la raíz.
