# Requisitos de comunicaciones

| ID    | Fuente                        | Criterio EARS                                                                                                                                                                                           |
| ----- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CO-01 | RF-25, APE03 CU 18 p. 15      | Cuando Secretaría publique una convocatoria para una asamblea o minga existente, el sistema deberá conservar sus datos y permitir la consulta a los destinatarios de la propia junta.                   |
| CO-02 | RF-26, CU 19 pp. 15–16        | Cuando Secretaría archive y publique un acta, resolución o acuerdo, el sistema deberá conservar su fecha, responsable y PDF y ofrecer acceso a los miembros autorizados.                                |
| CO-03 | RF-29, CU 20 p. 16            | Cuando Secretaría registre un oficio recibido, el sistema deberá conservar institución, fecha, asunto y archivo bajo acceso de Secretaría.                                                              |
| CO-04 | RF-33, CU 22 pp. 17–18        | Cuando un Administrador local o Socio intercambie mensajes, el sistema deberá verificar cuentas y membresías activas dentro de su junta y limitar cada conversación a sus participantes.                |
| CO-05 | Identidad 1B y aislamiento M2 | Si la junta, destinatario, rol o recurso no corresponde a la sesión, se denegará lectura, escritura o descarga. Las mutaciones dejarán evidencia sin texto ni archivos en los registros de diagnóstico. |

Las publicaciones se entregan dentro del sistema. Los adjuntos digitales y las fechas forman parte del documento publicado o archivado. No se configura mensajería externa en este corte.
